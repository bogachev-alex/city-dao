# Открытые государственные API Казахстана для Straita

## 1. Госзакупки — goszakup.gov.kz (самый ценный источник)

**GraphQL API** на `ows.goszakup.gov.kz/v3/graphql` — даёт реальные данные по строительным контрактам Алматы.

Что можно вытянуть:

- **Реестр договоров** — сумма, подрядчик, статус, даты
- **Объявления о закупках** (trd_buy) — фильтр по региону (Алматы) и категории (строительство)
- **Информация о поставщиках** — БИН, название, история участия
- **Лоты и планы закупок**

Для доступа нужен токен — получается бесплатно через [портал разработчика](https://goszakup.gov.kz/ru/developer/ows_v2). Есть [документация по GraphQL schema](https://ows.goszakup.gov.kz/help/v3/schema/).

**Как использовать в проекте:** заменить `DEMO_CONTRACTS` реальными контрактами из API — суммы, подрядчики, сроки будут настоящие.

## 2. Портал открытых данных — data.egov.kz

**REST API v4** с ключом (бесплатный). 3000+ датасетов, в том числе:

- Исполнение бюджета Алматы (от Управления стратегии и бюджета г. Алматы)
- Выданные разрешения на строительство
- Земельные участки
- Данные по районам города

Формат: `GET /api/v4/{dataset}?apiKey={key}`

**Как использовать:** показывать реальный бюджет районов на странице `/treasury/[district]`.

## 3. API Министерства финансов

Через [АО «Центр электронных финансов»](https://ecc.kz/ru/project/api-servisy-min-fina-rk) — 60+ сервисов в формате Open API:

- Планирование и исполнение бюджета
- Казначейские данные

**Как использовать:** реальные данные о расходах бюджета по программам строительства.

## Приоритеты интеграции

| Приоритет | Источник | Что даёт проекту |
| --------- | ------------------------------------ | ------------------------------------------------------------ |
| **1**     | goszakup.gov.kz GraphQL             | Реальные контракты на карте Алматы с суммами и подрядчиками  |
| **2**     | data.egov.kz — бюджет               | Реальные цифры бюджета районов для `/treasury`               |
| **3**     | data.egov.kz — разрешения на строит. | Подтверждение легитимности контрактов                        |

## План интеграции

```
lib/goszakup.ts              — GraphQL-клиент к API госзакупок
lib/opendata.ts              — REST-клиент к data.egov.kz
app/api/contracts/route.ts   — серверный прокси (чтобы не светить токены)
```

Данные кешировать через Next.js `revalidate` (раз в час достаточно) — так демо будет показывать живые данные без лишних запросов.
